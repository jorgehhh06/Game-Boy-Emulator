Game Boy Emulator written in Java, in the future C and C++ versions will be added, as well as documentation in english.
I tried to make the most accurate Game Boy Emulator I could without entering cycle-accurate bugs and complexity.
All of Blargg's test (excluding oam bug and audio) pass.
Audio is excluded for now.

It was created using IntelliJ and is recommended for modifying the code and building the project.

The emulator passes several Blargg tests and DMG ACID 2.
